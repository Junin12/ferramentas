DWG muito antigo ou muito novo pode não abrir; nesse caso, salve como DXF no AutoCAD.

DWG pesado ou que não abre? Converta para DXF no computador

O ODA File Converter é gratuito e converte uma pasta inteira de uma vez. DXF abre bem mais rápido aqui.

  1. No computador, baixe o ODA File Converter no site opendesign.com (menu Guest Files › ODA File Converter) e instale.
  2. Abra o programa. Em Input Folder, escolha a pasta com os DWG; em Output Folder, uma pasta vazia.
  3. Em Output version, escolha ACAD2018 e, em Output File type, DXF.
  4. Clique em Start. Os DXF ficam na pasta de saída: mande para o celular e abra aqui.
