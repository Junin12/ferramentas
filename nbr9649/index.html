Vazão de esgoto

Q = C·K1·K2·P·q / 86400 + Qinf (L/s) C = 0,8 retorno água → esgoto K1 = 1,2 dia de maior consumo K2 = 1,5 hora de maior consumo q = consumo (L/hab·dia) · P = população
vazão mínima de cálculo: 1,5 L/s por trechoinício (Qi) e fim de plano (Qf)
Use a taxa de infiltração e o consumo per capita adotados pela concessionária local.
